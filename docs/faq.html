Questions fréquentes

Ce site est-il affilié à NationsGlory ?

Non. NGBE Launcher est un projet communautaire indépendant, créé par des joueurs. Il n'est ni développé, ni géré, ni approuvé par NationsGlory ou WebNations SARL.

Le launcher est-il gratuit ?

Oui, entièrement gratuit.

Pourquoi Windows affiche un avertissement "Éditeur inconnu" ?

Parce que l'exécutable n'est pas signé avec un certificat de signature de code payant. C'est le cas de la plupart des petits logiciels gratuits distribués en dehors du Microsoft Store — ça ne veut pas dire que le fichier est dangereux.

Que fait exactement le launcher avec mes données ?

Le launcher affiche des informations publiques de ton profil NationsGlory (pseudo, description, pays, rang, temps de jeu) via un serveur relais qui interroge l'API publique de NationsGlory. Aucune donnée personnelle n'est collectée ou stockée ailleurs que sur ta propre machine (pseudo, préférences).

Le launcher modifie-t-il le jeu (triche, mods) ?

Non. NGBE Launcher se contente de lancer Minecraft Bedrock et de le connecter à un serveur — il ne modifie ni n'injecte rien dans le jeu.

Un serveur ne fonctionne pas / le launcher plante

Vérifie que Minecraft Bedrock est bien installé depuis le Microsoft Store. Si le problème persiste, signale-le sur le dépôt du projet.
